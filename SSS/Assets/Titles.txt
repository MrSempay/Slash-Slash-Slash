	README:
		Text in "=" tabs will not be deserialize.
		Here uses next text deserialize markers:
		
			1) H - text after "::" separator will be deserialize like a header text, example:
				H::SOME_TEXT
			SOME_TEXT will be deserialize like a header.
			
			2) D - text after "::" separator will be deserialize like a description text, example:
				D::SOME_TEXT
			SOME_TEXT will be deserialize like a description.
			
			3) S - will be deserialize as a separator, for example:
				S::
			No need text after "::".
			
			A certain realisation of this text types see in Assets/Scripts/UI/ScrollFadeController
